# Night Museum — gesture gallery

## Запуск
1. Откройте `index.html` в **Google Chrome**: правый клик → «Открыть в программе» → Google Chrome.
2. Нажмите **Enable camera** и разрешите доступ к камере.
3. Нужен интернет: MediaPipe, модель жестов и картины загружаются при открытии (видео с камеры никуда не отправляется).

## Жесты
| Жест | Действие |
|---|---|
| Быстрый взмах рукой влево / вправо | следующая / предыдущая картина |
| Открытая ладонь, держать ~0,5 с | пауза / продолжить |
| Щипок (большой + указательный), держать | открыть картину |
| Две открытые ладони, держать ~0,5 с | закрыть картину |

Кнопки внизу экрана дублируют все действия.

## Для теста
- Клавиша **D** — показать служебную панель: точки руки на превью и значения распознавания.
- `index.html?crossed` — включить экспериментальное закрытие скрещёнными руками (дополнительно загружает модель позы).
- Если картина с Wikimedia не загрузилась, берётся локальная копия из `gallery/`.
